# booping benchmarks — run archive

Generated artifacts of [claude-booping](https://github.com/A/claude-booping) model-benchmark runs, moved out of the plugin repo to keep it lean.

- `runs/` — one machine-shaped detail report per run.
- `reports/` — one human-readable report per run, linked from the scorecard.

The scorecard table, the method behind every column, and the scoring script live with the framework in the plugin repo under [`vault/benchmarks/`](https://github.com/A/claude-booping/tree/master/vault/benchmarks) — `history.md` rows link into this archive.
